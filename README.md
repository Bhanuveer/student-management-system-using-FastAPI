# Student Management System

A Full Stack Student Management System built using React, FastAPI, MongoDB, and JWT Authentication.

## Features

* User Registration and Login
* JWT Authentication
* Protected Routes
* Dashboard Statistics
* Add Student
* Edit Student
* Delete Student
* Search Students
* Pagination
* Sorting
* Loading States
* Delete Confirmation

## Tech Stack

### Frontend

* React
* React Router DOM
* Axios
* CSS

### Backend

* FastAPI
* MongoDB
* JWT Authentication
* Pydantic
